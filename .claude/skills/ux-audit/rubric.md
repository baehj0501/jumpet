# UX Evaluation Rubric

This rubric is shared across Discovery (baseline), Sprint Contract (target), and Evaluation (scoring).
Each criterion is scored 1–10. **If even one item is below its threshold, it is a fail.**

---

## 1. Design Quality (threshold: 7)

**Evaluation items**:
- Is the color palette consistent and intentional?
- Does the typographic scale form a clear hierarchy?
- Is the layout grid applied consistently?
- Do the visual elements converge into a single identity?

**Scoring guide**:
- 1-3: Visual inconsistencies are immediately noticeable (clashing colors, mixed fonts, broken alignment)
- 4-6: Basically consistent but with detail-level inconsistencies (uneven spacing, slight color differences)
- 7-8: An intentional and consistent visual system, with only minor improvements remaining
- 9-10: A precise visual system at a professional designer level

## 2. Originality (threshold: 6)

**Evaluation items**:
- Is it avoiding using a framework's default theme as-is (e.g., Ant Design defaults)?
- Are there intentional design decisions that fit the product's character?
- Is there evidence of custom thinking in the component composition and layout?

**Scoring guide**:
- 1-3: Framework defaults as-is (default colors, default layout, default components)
- 4-6: Partial customization (colors changed but layout left at defaults)
- 7-8: A clear design language reflecting the product identity
- 9-10: Original yet without harming usability

## 3. Craft (threshold: 7)

**Evaluation items**:
- Typographic hierarchy: are the size/weight differences between title/body/caption clear?
- Spacing consistency: is the spacing between elements in the same context identical?
- Color harmony: is the background-foreground contrast at or above the WCAG AA standard (4.5:1)?
- Alignment: are elements aligned to an invisible grid?
- Detail: are fine elements like borders, shadows, and rounding consistent?

**Scoring guide**:
- 1-3: Many instances of broken alignment, irregular spacing, and insufficient contrast
- 4-6: Generally good but with inconsistencies across pages
- 7-8: High consistency, intentional detail, with only minor inconsistencies remaining
- 9-10: Pixel-perfect precision

## 4. Functionality (threshold: 8)

**Evaluation items**:
- Can a first-time user of the interface discover the main features?
- Are the current state and the available actions clear?
- When an error occurs, does it guide the user on what to do?
- Does the empty state prompt the next action?
- Is loading/processing state fed back?

**Scoring guide**:
- 1-3: Core features can't be found or don't work
- 4-6: Features work but have low discoverability or insufficient feedback
- 7-8: Most features are intuitive, with insufficient guidance in edge cases
- 9-10: Clear guidance in every state (normal, empty, error, loading)
