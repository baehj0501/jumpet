# 프로젝트 개요

## 한 줄 정체성

> OS 바탕화면 위에 상시 떠 있는 **캐릭터(강아지)** 와, 우클릭으로 호출되는 **9개 패널**(먹이·놀이·to-do·가챠·아이템·운세·정보·링크·종료) 로 구성된 Electron 기반 데스크탑 펫 게임.

단순한 마스코트가 아니라 **펫 인터랙션 + 일상 도우미(메모/링크) + 가벼운 수집/가챠 루프** 가 결합된 형태를 지향한다.

## 사용자 가치 (왜 만드는가)

- **상시 동반자**: 화면 한 켠에 살아 있는 펫. 자율 walking, 드래그, 클릭 반응, 표정 모션 같은 가벼운 인터랙션.
- **정서적 케어 루프**: 먹이/놀이로 펫과 상호작용 → 점수 획득 → 가챠로 새 아이템 → 펫 외형 꾸미기로 다시 정서 충족.
- **일상 도우미**: 우클릭 메뉴에서 To-Do(완료 시 점수 보상), 링크(자주 쓰는 사이트 미니 버튼), 운세 같은 잡다한 기능.
- **놀이형 모티브**: 운세·가챠·중복 환원 등 작은 도파민 요소를 곳곳에 배치 — 사용자가 매일 한 번씩 들여다볼 이유를 만든다.

## 영감과 차별점

### 영감
- Tumblbug **"에그덕 키우기"** — 방치형 클리커 데스크탑 마스코트.

### 차별점
- 에그덕은 **단일 인터랙션(클릭) + 단일 가챠 루프**에 집중. 우리는 그 위에 **메뉴 패널**(TODO/링크/운세 등 일상 도우미)을 얹어 "단순 펫 → 데스크탑 보조 도구"로 확장.
- 클리커/방치 루프를 그대로 베끼지 않고 **사용자가 능동적으로 인터랙션**(먹이/놀이/할 일 완료)할 때만 점수가 누적되는 방향.
- **운세** 같은 자동 보상으로 "매일 한 번씩 열어보고 싶은 이유" 부여.

## 도메인 코어 — 무엇을 만드는가

| 서브시스템 | 구성 |
|---|---|
| 캐릭터 시스템 | 표시, 자율 walking, 드래그, PNG 3프레임 애니메이션, GIF 표정 모션 |
| 행동 상태 | `idle`, `walking`, `sit`, `sleep`, `jump` 등 — 확률 기반 자율 전환 |
| 인터랙션 | 클릭(말풍선·애니메이션), 우클릭(메뉴), 쓰다듬기 |
| 패널 (우클릭 메뉴 9개) | 먹이주기 · 놀아주기 · To-Do · 가챠 · 아이템 · 운세 · 정보 · 링크 관리 · 종료 |
| 재화 | 점수(score) — 모든 인터랙션의 보상이자 가챠 비용 |
| 인벤토리 | 영구 아이템(머리·몸통·손·펫) + 소모성 아이템(먹이·놀이) |
| 보상 루프 | 인터랙션·TODO·운세 → 점수 → 가챠 → 아이템 → 펫 꾸미기/소모 |
| 도우미 | 링크 미니 버튼 (별도 플로팅 창) |

자세한 동작은 [`features/README.md`](./features/README.md)에서 기능별로 분기.

## 빌드/배포 모델

- **단일 사용자, 로컬 전용** — 서버·계정·인증 없음.
- 모든 사용자 데이터는 `electron-store`로 로컬 디스크에 저장 (`app.getPath('userData')`).
- **dev 단계** — 아직 외부 배포 사용자 없음. 데이터 마이그레이션 부담 작음.
- 지원 OS: macOS / Windows.

## 핵심 합의된 디자인 결정

이 결정들은 코드 안에 흩어져 있어서 명문화. 변경 시 큰 영향이 있으니 신중히.

| 결정 | 이유 |
|---|---|
| **윈도우 모델 A** — 캐릭터 윈도우 자체를 OS 레벨로 이동 | 풀스크린 transparent overlay는 다른 앱 클릭이 통과 안 되고 우클릭 메뉴 이벤트가 막힘. 캐릭터를 작은 OS 윈도우로 두면 자연스럽게 풀림 |
| **multi BrowserWindow** | 패널을 별창으로 띄움. 한 창 crash가 다른 창에 영향 X. 각 패널이 자기 entry HTML + renderer 프로세스 |
| **main이 모든 영속 데이터의 SSOT** | 멀티 윈도우가 같은 데이터를 봐야 함. `electron-store`로 영속화. IPC broadcast로 동기화 |
| **renderer는 Zustand 글로벌 store** | main 데이터의 read-only 미러. 모듈 로드 시 동기화 시작. 의미 단위 액션만 노출 |
| **타입은 `@shared/contracts/*`에서 공유** | main / preload / renderer가 동일 타입 정의. 각자 별도 선언 → cross-import 불가 → 동기 깨짐 위험을 차단 |
| **빌드 타임 에셋** | 런타임 외부 이미지 입력 X. PNG/GIF는 번들에 포함 |
| **혼자 개발 가정 — 과한 validation 지양** | 외부 입력(디스크 hydration, 산술 NaN)만 가드. IPC payload는 신뢰 |
| **CSS는 emotion `css` prop** | 비즈니스 UI. Tailwind/styled-components 미사용 |
