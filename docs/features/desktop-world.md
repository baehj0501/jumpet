# Desktop World (아이템 꾸미기) 기능 명세

> 아이템 시스템 재정의. 기존 "소모 아이템 인벤토리" 방향을 대체하고, **데스크탑 하단 월드를 꾸미는** 모델로 간다.
> (기존 소모 아이템/가챠 명세는 [`gacha-and-inventory.md`](./gacha-and-inventory.md). 둘의 관계는 Open Question — 아래 참고.)

## 개요

사용자는 데스크탑 하단의 **월드 영역**을 자신만의 스타일로 꾸민다. 획득한 아이템을 원하는 위치에 배치하고, 저장된 상태는 앱 종료 후에도 유지된다.

## 월드 영역

- 데스크탑 하단에 월드 영역 표시 / 저장된 월드 자동 로드 / 상태 저장 / 초기화.
- **규칙**: 항상 바탕화면 최하단 레이어. 다른 프로그램 창을 가리지 않음. 레이어 위치(순서)는 사용자가 변경 불가.

## 꾸미기 모드

- 진입: 꾸미기 버튼 클릭 / 아이템 메뉴 → 편집.
- 기능: 아이템 배치 · 이동 · 삭제.
- 종료: 저장 / 취소.

## 아이템 시스템

- 보유 아이템 목록 조회 · 선택 · 월드 배치 · 배치된 아이템 회수.
- 상태: **보관 중** / **배치 중**.

## 배치 시스템

- 드래그 앤 드롭 배치 · 위치 변경 · 위치 저장.
- 규칙: 월드 영역 내부에서만 배치. 저장 전까지 자유 수정. 저장 후 위치 고정.

## 저장 시스템

- 저장 데이터: 아이템 종류 · 위치(X, Y) · 배치 상태.
- 기능: 저장 · 자동 불러오기.

## 고정 모드

- 저장 완료 후 기본 적용 상태.
- 제한: 이동/삭제/편집 불가 (실수로 배치 변경 방지).

## 수정 기능

- 절차: 아이템 메뉴 → 꾸미기 모드 진입 → 수정 → 저장 → 고정 모드 복귀.
- 수정은 꾸미기 모드에서만, 고정 모드에서는 불가.

## 데이터 유지

- 앱 종료 후 유지, 재실행 시 저장된 월드 복원.

## 사용자 플로우

아이템 획득 → 보관함 저장 → 꾸미기 모드 진입 → 배치 → 저장 → 고정 모드 → 데스크탑 하단 유지 → 필요 시 다시 꾸미기 모드 진입 후 수정.

## 핵심 정책

1. 월드는 항상 데스크탑 최하단에 표시.
2. 저장 후 모든 아이템 고정.
3. 수정은 꾸미기 모드에서만.
4. 저장된 월드는 앱 재실행 후에도 유지.
5. 사용자는 아이템 위치만 변경, 레이어 순서는 변경 불가.

## 구현 메모 / Open Questions (작업 전 합의 필요)

- **월드 윈도우**: 캐릭터 윈도우처럼 별도 BrowserWindow(전체 폭, 화면 하단, transparent·frameless)로 만들고 "최하단 레이어"를 구현. macOS에서 다른 앱보다 항상 뒤로 보내는 건 제약이 있어 정확한 구현 방식 결정 필요.
- **아이템 소스**: 월드에 놓는 "획득한 아이템"의 카탈로그. 현재 코드의 소모 아이템(먹이/장난감)과는 별개의 **데코 아이템 세트**가 필요 → 신규 정의 필요.
- **가챠 연동**: 데코 아이템을 가챠로 획득할지, 별도 획득 경로인지.
- **SSOT 도메인**: `world`(배치된 아이템: type/x/y) + `mode`(edit/fixed) — main 영속(electron-store) + IPC broadcast.
