# 루프프 데스크메이트 — 발표 PT 작업지시서

> **용도**: Claude 디자인(아티팩트)으로 발표용 슬라이드 덱을 제작하기 위한 작업지시서.
> **대상/목적**: 교수님께 프로젝트 + 앱 소개 (학술/프로젝트 발표).
> **분량**: 상세판 — 기획 배경부터 기능·아키텍처·디자인·로드맵까지 전부.
> **비주얼 톤**: 귀엽고 포근(파스텔·둥근 카드) + **픽셀 요소를 포인트로**(계단형 모서리·픽셀 아이콘·Galmuri 폰트).

---

## 0. 한눈 요약 (제작자에게)

- 제품명: **루프프 데스크메이트 (Loopf Deskmate)** / 영문 로고는 대문자 `LOOPF DESKMATE`.
- 한 줄 정체성: **OS 데스크탑 위에 상시 떠 있는 캐릭터 + 우클릭하면 열리는 탭형 통합 메뉴 창**으로 구성된, 데스크탑 펫 + 일상 도우미 + 가벼운 수집/가챠 루프가 결합된 Electron 데스크탑 펫 게임.
- 슬라이드 수: **17장** (아래 구성 참고). 교수 발표라 *왜 만들었나(기획)·무엇을 만들었나(기능)·어떻게 만들었나(기술/설계)* 세 축이 모두 보이게 한다.
- 포맷: 16:9 가로. 슬라이드당 헤드라인 1개 + 핵심 메시지 1줄 + 근거 불릿 3~5개 + 비주얼 1개 원칙.

## 1. 디자인 가이드 (전 슬라이드 공통)

### 컬러 (앱의 스카이블루 테마에서 추출 — 실제 제품과 일치시킬 것)
- 배경: `#e8f4ff` (아주 옅은 하늘)
- 패널/카드: `#d4eaff`, 카드 내부 `#f4faff`
- 포인트(accent): `#3a8fc4`, 보조 `#5ab0e8`
- 본문 텍스트: `#0a3050` (네이비), 흐린 텍스트 `#5a90b8`
- 테두리: `#7bbde0`
- 강조/하이라이트 박스: accent에 흰 글자.
- 포근함을 위해 큰 면적은 파스텔, **픽셀 디테일에만 진한 accent**를 쓴다.

### 폰트
- **헤드라인·포인트 라벨·픽셀 UI 캡처**: `Galmuri11`(픽셀 폰트) 느낌. 없으면 픽셀계열 대체.
- **본문**: 둥글고 포근한 고딕(예: Pretendard / 나눔스퀘어라운드). 가독성 우선.
- 픽셀 폰트는 *포인트로만* — 본문 전체에 픽셀 폰트를 쓰지 말 것(가독성).

### 픽셀 포인트 규칙 (포근함 + 픽셀의 균형)
- 카드/버튼 모서리: 일반은 부드러운 라운드, **강조 요소 1~2개에만 "계단형(픽셀) 모서리"**를 적용해 포인트.
- 장식: 16×16 **픽셀 아이콘**(탭 아이콘 모티프), 반짝이(✦) 픽셀 스파클, 작은 픽셀 구름.
- 그림자: 부드러운 drop-shadow + 픽셀 요소엔 2~3px 오프셋 하드 섀도(드롭섀도) 혼용.
- 캐릭터(피요/쿠피/슈피/윙피) 일러스트를 여백에 작게 배치해 포근함 유지.

### 레이아웃 원칙
- 좌측 텍스트 / 우측 비주얼(또는 상단 헤드라인 + 하단 카드 그리드).
- 한 슬라이드 = 한 메시지. 불릿은 짧게.
- 진행 표시: 하단에 픽셀 도트로 챕터 표시(선택).

## 2. 슬라이드별 구성 (17장)

> 각 항목: **[헤드라인] / 핵심 메시지 / 내용 불릿 / 비주얼 지시**

### S1. 표지
- **헤드라인**: LOOPF DESKMATE / 루프프 데스크메이트
- 핵심 메시지: "내 책상 위에 사는 작은 동반자, 그리고 일상 도우미"
- 내용: 부제(한 줄 정체성), 발표자/소속/날짜.
- 비주얼: 캐릭터 4종이 데스크탑 하단에 옹기종기 + 픽셀 구름/반짝이. 로고는 대문자, 픽셀 포인트.

### S2. 프로젝트 개요
- **헤드라인**: 무엇인가요?
- 핵심 메시지: "상시 떠 있는 캐릭터 + 우클릭으로 열리는 통합 탭 메뉴."
- 내용 불릿:
  - 단순 마스코트가 아니라 **펫 인터랙션 + 일상 도우미 + 가벼운 수집/가챠 루프**의 결합.
  - 우클릭은 네이티브 드롭다운이 아니라 **픽셀아트 테마의 탭 창 하나**를 연다.
  - Electron 기반 데스크탑 앱(mac/win/linux).
- 비주얼: 좌측 캐릭터 윈도우, 우측 메뉴 창 목업을 화살표로 연결.

### S3. 배경 & 동기 (왜 만드는가)
- **헤드라인**: 왜 만들었나
- 핵심 메시지: "데스크탑 펫의 정서적 가치 + 라이트 캐주얼 게임의 재미를 한 화면에."
- 내용 불릿:
  - **상시 동반자**: 화면 한 켠에 살아 있는 펫(자율 보행·드래그·클릭 반응).
  - **정서적 케어**: 쓰다듬기/먹이/놀이 등 감정 루프(지향).
  - **일상 도우미**: 할 일·일정·타이머·운세·가챠 등 일상/수집 기능 결합.
  - 영감: Tumblbug "에그덕 키우기"(방치형 클리커 마스코트) — 단, 클리커/방치 루프를 그대로 베끼지 않고 **메뉴 패널 위주로 확장**.
- 비주얼: 좌(감정/펫) ↔ 우(생산성/게임) 두 원이 겹치는 벤다이어그램.

### S4. 타깃 & 사용자 가치
- **헤드라인**: 누구에게, 어떤 가치
- 핵심 메시지: "책상에서 일하는 사람에게 '곁에 있는 느낌'과 '가벼운 도우미'를 동시에."
- 내용: 사용자 가치 3가지 카드(상시 동반자 / 정서적 케어 / 일상 도우미).
- 비주얼: 3 카드 그리드, 각 카드에 픽셀 아이콘.

### S5. 핵심 컨셉 — 2개의 창
- **헤드라인**: 딱 두 종류의 창
- 핵심 메시지: "캐릭터 창 + 통합 메뉴 창. 모든 기능은 메뉴 창의 '탭'으로 산다."
- 내용 불릿:
  - **캐릭터 윈도우**: 300×300 투명·프레임리스, 일반 z-order(다른 앱처럼 깔리고 올라옴).
  - **통합 메뉴 창**: 우클릭으로 열리는 프레임리스 싱글톤. 별창 패턴 폐기.
  - (보조) 꾸미기 전체화면 오버레이 / 유튜브 별창.
- 비주얼: 두 창 목업 + "탭으로 통합" 라벨.

### S6. 캐릭터 시스템
- **헤드라인**: 살아 있는 캐릭터
- 핵심 메시지: "감정 × 행동을 분리한 2차원 카탈로그, 자율 행동까지."
- 내용 불릿:
  - 캐릭터 4종: **피요 / 쿠피 / 슈피 / 윙피**.
  - **행동 상태**(idle/walking, 확률 기반 자율 전환) × **감정**(default/happy/sad…) — 별개 축.
  - **자율 보행**(슈피가 화면 최상단에 있을 때 가끔 걷기), **클릭 시 랜덤 모션**(프레임 애니), 드래그 이동.
  - **말풍선**: 좌클릭 멘트(이름 호격/조사 처리), 시간대별 인사, 생일 축하 연출.
- 비주얼: 캐릭터 4종 + "감정×행동" 매트릭스 + 말풍선 예시.

### S7. 기능 전체 맵 — 탭 10종
- **헤드라인**: 하나의 창, 열 개의 탭
- 핵심 메시지: "돌봄부터 생산성·수집까지 한 창에."
- 내용: 탭 10종을 픽셀 아이콘 그리드로. 홈·일정·할일·타이머·운세·가챠·펫·아이템·유튜브·설정.
- 비주얼: 10개 픽셀 아이콘 카드 그리드(2×5), 각 한 줄 설명.

### S8. 기능 상세 ① — 홈 · 일정 · 할일
- **헤드라인**: 매일 쓰는 핵심
- 내용 불릿:
  - **홈**: 하늘/구름/반짝이 씬 + 캐릭터 좌우 전환 + 프로필 행(캐릭터 이름/내 이름/생일/생일 D-day) + ⭐포인트.
  - **일정**: 캘린더 + 년/월 드롭다운 + 일정 추가(시작/종료 날짜·시간) + 할일과 양방향 삭제 연동.
  - **할일**: 프로젝트(칩) 단위, 완료 보상 점수, 완료/취소 양방향 토글.
- 비주얼: 세 탭 캡처(또는 목업) 가로 배열.

### S9. 기능 상세 ② — 타이머 · 운세 · 가챠
- **헤드라인**: 집중과 재미
- 내용 불릿:
  - **타이머**: 포모도로 + 픽셀 스톱워치, 완료 시 캐릭터 알림.
  - **운세**: 수정구슬 애니(사인파 그라데이션), 등급 + 점수 보상.
  - **가챠**: 가챠 머신 연출, 포인트로 뽑기(음수면 불가).
- 비주얼: 수정구슬/가챠 머신 픽셀 일러스트.

### S10. 기능 상세 ③ — 펫 · 아이템 · 유튜브 · 설정
- **헤드라인**: 꾸미고 확장하기
- 내용 불릿:
  - **펫**: 동반 펫 장착(캐릭터와 별개 축), 캐릭터 우하단에 렌더.
  - **꾸미기(월드)**: 데코 배치 전체화면 오버레이.
  - **유튜브**: 테마 프레임 별창.
  - **설정**: 테마 6종(`data-theme` 전환) + 캐릭터 크기 슬라이더 + 내 정보 + 앱(버전/초기화/종료/로그인 시 자동실행).
- 비주얼: 설정 테마 6종 스와치 + 펫 카드.

### S11. (하이라이트) 알림 시스템
- **헤드라인**: 놓치지 않게, 곁에서 알려준다
- 핵심 메시지: "할일·일정·타이머가 때가 되면, 캐릭터가 맨 위로 올라와 알린다."
- 내용 불릿:
  - **할일 알림**: 마감 날짜 + '당일/하루 전 × 오전/오후' 칩으로 간단 설정.
  - **일정 알람**: 시작 시각 기준 'N분 전' 오프셋.
  - **타이머 완료** 알림.
  - 매일 **아침·저녁 남은 할일 리마인더**.
  - 알림이 뜨면 캐릭터가 **최상단으로 올라오고**, 말풍선은 **닫을 때까지 유지(sticky)**.
- 비주얼: 캐릭터가 다른 창 위로 올라와 sticky 말풍선을 띄운 장면(닫기 ✕ 표시).

### S12. 기술 아키텍처 — 멀티 윈도우
- **헤드라인**: 어떻게 동작하나 (1) 창 구조
- 핵심 메시지: "윈도우 모델 A — OS 레벨 창을 직접 이동/제어."
- 내용 불릿:
  - 캐릭터 창(투명·프레임리스, setPosition으로 이동), 메뉴 창(싱글톤), 월드 오버레이, 유튜브 별창.
  - 풀스크린 투명 오버레이 대신 OS 창 이동을 택한 이유(우클릭 contextmenu 정상 동작, 다른 앱 클릭 자연 통과).
- 비주얼: 4개 윈도우 관계 다이어그램.

### S13. 기술 아키텍처 — 데이터(SSOT) & IPC
- **헤드라인**: 어떻게 동작하나 (2) 상태 관리
- 핵심 메시지: "모든 영속 데이터는 main이 SSOT, IPC로 모든 창에 broadcast, renderer는 Zustand 미러."
- 내용 불릿:
  - 도메인별 동일 패턴: `contracts/{domain}Events.ts` → main `{state,store,ipc,index}` → renderer `use{Domain}Store`.
  - electron-store 영속화 + apply→reduce→write→broadcast.
  - 도메인: player/todo/fortune/item/schedule/characterSelection/profile/petSelection/world/settings.
- 비주얼: main(SSOT) → IPC → 여러 renderer 창으로 뻗는 broadcast 다이어그램.

### S14. 폴더 아키텍처 — FSD-lite + 3-tier
- **헤드라인**: 코드 구조
- 핵심 메시지: "Electron 3-tier(main/preload/renderer) + 렌더러는 FSD-lite 레이어."
- 내용 불릿:
  - `shared → entities → features → widgets → app/pages` 단방향 의존.
  - 각 slice는 `index.ts` barrel로 public API만 노출.
  - 새 탭 추가 흐름: 도메인 SSOT → `tabs/{Name}Tab.tsx` → MenuPage 등록.
- 비주얼: 폴더 트리(요약) + 의존 방향 화살표.

### S15. 핵심 설계 결정
- **헤드라인**: 선택과 근거
- 내용 불릿(결정 → 이유):
  - 윈도우 모델 A 채택.
  - 자율 행동 일시정지를 `isInteractingRef` 단일 채널로(드래그+메뉴 공유, behaviors는 read-only).
  - 빌드 타임 에셋(런타임 추가 없음).
  - 상태 머신 캡슐화(의미 단위 액션만 노출).
  - CSS 정책: 비즈니스 UI는 emotion, 메뉴 창은 className 기반 픽셀 테마.
- 비주얼: 결정 카드 4~5개.

### S16. 디자인 시스템 & 기술 스택
- **헤드라인**: 보이는 것과 쓰인 것
- 내용 불릿:
  - 디자인: 픽셀 테마(계단형 모서리 clip-path 토큰, 컬러 베벨, 6종 테마, Galmuri11 폰트, 16×16 다색 픽셀 탭 아이콘).
  - 스택: Electron + electron-vite, React + TypeScript, Zustand, emotion.
  - 배포: electron-builder(mac dmg arm64/x64 · win nsis · linux AppImage).
- 비주얼: 좌측 디자인 토큰 스와치/모서리 샘플, 우측 기술 로고 그리드.

### S17. 로드맵 & 마무리
- **헤드라인**: 다음 단계 / 마무리
- 내용 불릿:
  - 향후: 감정 케어 루프 확대, 행동 상태(sit/sleep/jump) 확장, 아이템 탭 본구현 등.
  - 요약 한 줄 + 데모 안내 + Q&A.
- 비주얼: 캐릭터들이 손 흔드는 픽셀 장면 + "감사합니다".

## 3. 콘텐츠 소스 (사실 확인용 — 슬라이드에 반영)

- 캐릭터 4종: 피요/쿠피/슈피/윙피 (이름 고정·수정 불가).
- 탭 10종: 홈·일정·할일·타이머·운세·가챠·펫·아이템·유튜브·설정 (아이템/유튜브는 일부 placeholder, 코드가 진실 — 캡처 시점 기준 확인).
- 테마 6종: 스카이블루(기본)/연두/베이비핑크/브라운/라이트/다크.
- 알림: 할일(날짜+칩) / 일정(오프셋) / 타이머 / 아침·저녁 리마인더 + sticky 말풍선 + 캐릭터 끌어올림.
- SSOT 도메인 10종(위 S13 목록).
- 영감 출처: Tumblbug "에그덕 키우기".

> ⚠️ 캡처/스크린샷이 필요한 슬라이드: S6(캐릭터), S8~S10(탭), S11(알림), S16(테마 스와치). 실제 앱 화면을 캡처해 픽셀 포인트 프레임에 끼워 넣을 것.

## 4. Claude 디자인에 붙여넣을 제작 프롬프트 (요약본)

```
17장짜리 16:9 발표 슬라이드 덱을 만들어줘. 주제는 'LOOPF DESKMATE(루프프 데스크메이트)'라는
Electron 데스크탑 펫 + 일상 도우미 앱의 교수님 대상 프로젝트 발표야.

톤: 귀엽고 포근한 파스텔(둥근 카드) + 픽셀 요소를 포인트로(계단형 모서리, 16x16 픽셀 아이콘, 반짝이).
컬러: 배경 #e8f4ff, 카드 #d4eaff/#f4faff, 포인트 #3a8fc4/#5ab0e8, 텍스트 #0a3050, 테두리 #7bbde0.
폰트: 헤드라인/포인트는 픽셀 폰트(Galmuri 느낌), 본문은 둥근 고딕(Pretendard 등).
한 슬라이드 = 한 메시지(헤드라인 + 한 줄 + 불릿 3~5 + 비주얼 1).

슬라이드 순서와 내용은 아래 구성을 그대로 따라줘:
[여기에 위 'S1~S17' 헤드라인+불릿을 붙여넣기]
```

> 사용법: 위 코드블록을 복사하고, 대괄호 부분에 S1~S17 내용을 채워 Claude 디자인에 전달하면 된다.
> 분량을 줄이려면 S8~S10을 하나로 합쳐 14장, 더 줄이면 S11~S15 압축으로 10장까지 가능.
